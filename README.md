# Snow Crash

Snow Crash is a Godot-based game project.

## Windows demo

The Windows demo is version **0.3.0**. The downloadable ZIP still needs to be attached as a GitHub Release asset.

Once the release is available:

1. Download the Windows demo ZIP from the Releases section.
2. Extract it to a folder.
3. Run `SnowCrash.exe`.

If the demo fails to launch, try `SnowCrash.console.exe` for diagnostic output.
