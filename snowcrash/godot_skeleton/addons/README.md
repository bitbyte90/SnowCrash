# Addons to install (not included in the skeleton)

| Addon | Why | Licence |
|---|---|---|
| Godot XR Tools | Hands, pickup, teleport arc, snap turn, vignette | MIT |
| GDE GoZen (or EIRTeam.FFmpeg) | MP4/MKV/WebM video playback via FFmpeg | check each repo (LGPL / MIT) |
| godot-sqlite | The file index database | MIT |
| snowcrash_native (ours, later) | ReadDirectoryChangesW watcher, Windows shell thumbnails, ShellExecuteExW launcher, Everything3 SDK client | GPL-3.0 (with the project) |

Install from the Godot Asset Library where available, or copy each into `addons/<name>/` and enable it in Project Settings → Plugins.
